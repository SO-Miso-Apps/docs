# Customizer Overview

Visual control center for styling your sticky cart with instant preview.

## Access

**Shopify Admin** → **Apps** → **Sticky Add to Cart** → **Open Customizer**

## Interface Layout

### Left Panel - Control Tabs

| Tab | Purpose |
|-----|---------|
| **Presets** | 25+ ready-made themes |
| **General** | Display type, visibility, buy now |
| **Colors** | Buttons, badges, text |
| **Typography** | Fonts, sizes, weights |
| **Spacing** | Radius, padding, gaps |
| **Effects** | Button animations (8 effects) |
| **Languages** | Translations, custom text |

### Center Panel - Live Preview

- ⚡ **Instant updates** - No refresh needed
- 📱 **Device toggle** - Switch mobile/desktop
- 🎯 **Interactive** - Test functionality
- ✅ **Realistic** - Actual product display

### Right Panel - Code Export

- Export configuration JSON
- Manual integration code
- Settings backup

## Workflow

```
Choose Preset → Adjust Colors → Set Typography → 
Fine-tune Spacing → Configure Display → Add Translations → 
Preview & Test → Save & Deploy
```

## Common Tasks

| Task | Steps |
|------|-------|
| Change button color | Colors tab → Primary Button BG → Select color |
| Make buttons rounder | Spacing tab → Border Radius → Increase |
| Add Buy Now button | General tab → Show Buy Now → Toggle ON |
| Apply preset | Presets tab → Choose → Apply |
| Translate text | Languages tab → Select language → Enter |

## Best Practices

:::tip Customization Tips
1. **Start with preset** - Don't build from scratch
2. **Preview both views** - Mobile AND desktop
3. **Save frequently** - Protect your work
4. **Test interactions** - Click buttons in preview
5. **Keep it simple** - Don't over-customize
:::

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Tab** | Navigate fields |
| **Enter** | Apply changes |
| **Esc** | Close color picker |
| **↑↓** | Adjust sliders |

## Troubleshooting

**Preview not updating?**
- Hard refresh (Cmd+Shift+R / Ctrl+Shift+R)
- Clear browser cache

**Changes not on store?**
- Click Save, then Deploy
- Wait 1-2 minutes
- Clear store cache
