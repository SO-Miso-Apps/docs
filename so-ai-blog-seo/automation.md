# Automation

Automation works best when the manual workflow already feels stable.

## Which parameters matter most for automation?

Automation depends on defaults, so the reusable parameters in Settings carry most of the quality burden.

When posts are generated automatically, the app cannot rely on ad hoc manual tuning each time. That is why default article type, default tone, default CTA, merchant notes, and default fact pack are especially important.

If automation outputs feel inconsistent, the problem is often not the schedule itself. It is usually that the inherited parameter defaults are too vague, too generic, or not aligned with the intended content program.

### Recommended approach

- Stabilize your reusable parameter defaults first.
- Test those settings with manual drafts before enabling automation.
- Treat automation as a multiplier of parameter quality, not a replacement for it.

**Best for:** Stores scaling content through reusable, parameter-driven defaults.

**In app:** Settings
